A program that draws an invented passport spread for the Free State of Skerry: a data page with an engraved portrait and a machine-readable zone with correct check digits, a Kestrelia visitor visa, eight arrival and departure stamps from three neighbouring countries, a Port Anselm tide table, and the harbour-dues stamp. Every date is consistent — no stamp predates the passport's issue.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
